# Requirements

## 1. 개요
**"나의 조그만 전기차"** 프로젝트는 STM32 및 ESP32 기반의 임베디드 시스템을 활용하여 전기차의 핵심 기능을 소형 RC카로 구현하는 프로젝트입니다. 이 문서는 시스템의 기능적 및 비기능적 요구사항을 정리한 문서입니다.

---

## 2. 기능적 요구사항 (Functional Requirements)

### 2.1 주행 및 조향 기능
- [ ] DC 모터를 이용한 후륜 구동 (전진, 후진, 정지)
- [ ] 서보모터를 이용한 전륜 조향 (좌회전, 우회전)
- [ ] 속도 및 조향각 조절 기능
- [ ] 컨트롤러를 통한 수동 주행 모드 지원
- [ ] 장애물 감지 시 자동 정지 기능

### 2.2 센서 및 환경 인식 기능
- [ ] **전방 초음파 센서**를 이용한 장애물 감지 및 거리 측정
- [ ] **ESP32-CAM**을 이용한 전방 시각 정보 수집
- [ ] 장애물 감지 데이터 및 카메라 데이터를 기반으로 판단 로직 적용

### 2.3 통신 기능
- [ ] **CAN 통신**을 통해 ECU 간 데이터 송수신
  - **ESP32 센서 ECU → STM32 VCU**: 장애물 거리 데이터, 카메라 분석 데이터
  - **STM32 VCU → ESP32 컨트롤러 ECU**: 주행 상태 정보, 경고 메시지
- [ ] **BLE 통신**을 이용한 컨트롤러 입력 수신
- [ ] **UART 통신**을 통한 디버깅 및 로그 출력 기능

### 2.4 제어 및 인터페이스
- [ ] BLE 기반 컨트롤러 입력을 해석하여 주행 명령 전송
- [ ] 원격 제어 및 명령어 기반 주행 가능
- [ ] 장애물 감지 시 자동 회피 알고리즘 구현

### 2.5 전력 관리
- [ ] **18650 배터리** 3개를 이용한 전원 공급
- [ ] **DC-DC 변환기**를 이용하여 5V 전원 공급
- [ ] 배터리 잔량 감지 및 경고 기능

---

## 3. 비기능적 요구사항 (Non-functional Requirements)

### 3.1 시스템 성능
- [ ] 실시간 주행 및 조향 반응 속도 ≤ 100ms
- [ ] CAN 메시지 송수신 지연 ≤ 10ms
- [ ] BLE 통신 응답 속도 ≤ 50ms

### 3.2 확장성 및 유지보수성
- [ ] 추가 센서 및 기능 확장 가능하도록 설계
- [ ] 모듈화된 코드 구조로 유지보수 용이성 확보

### 3.3 개발 환경 및 도구
- [ ] **STM32 개발 환경**: VSCode + GCC Toolchain + GDB + OpenOCD
- [ ] **ESP32 개발 환경**: ESP-IDF + GCC Toolchain
- [ ] **소스 코드 관리**: GitHub 활용
- [ ] **자동화 빌드 및 디버깅 스크립트 제공**

### 3.4 안전성
- [ ] 주행 중 장애물 감지 시 자동 정지
- [ ] 비정상적인 입력값 감지 및 오류 처리
